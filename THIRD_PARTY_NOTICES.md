# Third-Party Notices and Asset Review

Illuminated Documents v1.11.1 has no bundled runtime package dependencies and no vendored third-party JavaScript libraries.

## Foundry VTT

The module integrates with the Foundry Virtual Tabletop public module API. Foundry VTT itself is not included in this repository and remains subject to Foundry Gaming LLC's terms and licenses.

## Icons

User-interface icon class names reference Font Awesome icons supplied by Foundry VTT at runtime. Font Awesome font files and CSS are not redistributed by this module.

## Module-owned asset

`assets/backgrounds/parchment.svg` is treated as module-owned artwork and is distributed under the repository's AGPL-3.0-or-later licence.

## User-provided assets

Background images and font files selected or uploaded through the module are user-provided content. They are not included in this repository. Users are responsible for ensuring they have the right to use and redistribute those files.

## Review requirement

Before publishing a fork containing additional images, fonts, or other media, review the license and redistribution terms for every added asset. Do not assume that the repository's AGPL licence applies to third-party or proprietary material.
