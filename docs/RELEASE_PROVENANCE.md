# Release Provenance

Version 1.12.0 is a feature release built directly from the accepted, reproducible Illuminated Documents v1.11.1 source repository delivered in this conversation. No earlier runtime archive was used to reconstruct the module.

The release adds optional Journal section chapters while retaining the v1.11.1 Foundry V13 Journal ApplicationV2 integration and the v1.11.0 scalable virtualized renderer. Existing documents remain in single-page mode by default and require no manual migration.

The complete-book metadata remains authoritative on the Journal. Managed chapter pages store only their stable section ID, avoiding metadata duplication and allowing page identity to survive section rename and reorder operations.
